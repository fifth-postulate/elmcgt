# Elm Computational Group Theory
This project contains Elm code to do [__computational group theory__][cgt].
Computational group theory is

> the study of groups by means of computers.

## Plans
We plan to provide means to calculate with

* Scheier-Sims algorthim.
* Todd-Coxeter algorithm.
* Automatic groups.

[cgt]: https://en.wikipedia.org/wiki/Computational_group_theory
